# 视觉设计：让学习网页“想读、读得下去”

> 这一份解决“好不好看、像不像正经作品”。排版的失败不会报错，但会直接让人关掉页面。

## 1. 设计目标

不是“花哨”，而是四个具体感受：

1. **像一本正经出版物**：有封面、有版心、有章节层级。
2. **读起来不费劲**：字号、行高、行宽、对比度合适。
3. **有质感但不喧宾夺主**：装饰服务于内容，不抢注意力。
4. **完整度**：深色模式、打印、手机、搜索、进度都考虑到。

## 2. 三条硬规矩

### 2.1 先定三色 + 两字体

```css
:root {
  --paper: #f6f3ec;     /* 背景：米色纸 */
  --ink: #1d2633;       /* 正文：墨蓝黑 */
  --ink-2: #39465a;     /* 次级文字 */
  --muted: #6c7a8d;     /* 注释 */
  --line: #e3dccc;      /* 分隔线 */
  --accent: #0f766e;    /* 强调：松绿 */
  --accent-2: #b45309;  /* 点缀：赭石 */
  --card: #fffdf8;      /* 卡片 */
  --serif: Georgia, "Noto Serif SC", "Songti SC", serif;
  --sans: system-ui, "PingFang SC", "Microsoft YaHei", sans-serif;
  --mono: "Cascadia Code", Consolas, monospace;
}
```

规则：

- **标题衬线，正文无衬线**（学术/阅读型）；工程文档可全无衬线；
- 强调色 **最多两个**，其中一个只做小面积点缀；
- 不直接用纯黑 `#000` 和纯白 `#fff`，用带一点色相的黑白。

### 2.2 版心与节奏

| 项 | 建议 |
|---|---|
| 正文宽度 | 65–75 字符（中文约 36–42 字/行） |
| 正文字号 | 16–17px（桌面）；手机 16px |
| 行高 | 1.75–1.9 |
| 段间距 | 0.7–1em |
| h2 / h3 / 正文比例 | 1.6–1.9 : 1.25 : 1 |
| 卡片内边距 | 16–24px；卡片间距 12–16px |
| 页面留白 | 大屏左右 ≥48px；首屏顶部 ≥40px |

### 2.3 视觉层级必须“一眼可辨”

同一页至少能区分五层：**封面 → 章首 → 小节标题 → 正文 → 辅助信息**。

- 章首：kicker（小号等宽大写）+ 衬线 h2 + 一句说明；
- 小节：衬线 h3 + 左侧强调竖线（或编号）；
- 正文：常规字重；
- 辅助：muted 色、小一号；
- 交互：按钮/链接用强调色，但面积小。

## 3. 风格选择表

| 主题类型 | 气质 | 字体 | 颜色 | 装饰 |
|---|---|---|---|---|
| 论文/学术 | 学术手册 | 衬线标题 + 无衬线正文 | 米纸 + 墨蓝 + 松绿/赭石 | 细线、编号、脚注感 |
| 教材/课程 | 教科书 | 衬线标题 + 无衬线正文 | 白纸 + 深蓝 + 橙 | 章节色带、目标框、练习框 |
| 工程技术 | 文档站 | 无衬线为主 | 白/浅灰 + 蓝 | 代码块、侧栏树、徽标 |
| 科普/大众 | 杂志 | 大号衬线/黑体标题 | 高对比 + 大色块 | 大图、引文、数字卡 |
| 笔记/个人 | 手账 | 衬线/手写感标题 | 米黄 + 棕 | 贴纸感、虚线、标签 |

**不要混搭**：学术手册不要配荧光渐变按钮；杂志风不要配密集表格。

## 4. 组件库（可直接抄结构）

### 4.1 封面 hero

```
[眉标：STUDY GUIDE · ...]
[H1 大标题，关键词用强调色]        ← 衬线，clamp(34px, 4.6vw, 56px)
[副标题行，较小]
[摘要 2–3 句，关键词加粗]
[chips：5 篇论文 · 154 页 | 8 章 · 142 节 | 46 术语 | 离线]
[hero-grid：3–5 张主题卡，每张 序号 + 标题 + 1–2 句]
[CTA：主按钮（开始阅读）+ 次按钮（去闯关）+ 打印]
[callout：这份材料怎么来的 / 使用建议]
```

要点：标题最多两行；主题卡等高；卡片文字 ≤ 3 行；CTA 不超过 3 个。

### 4.2 侧栏目录

- 品牌区（色块 logo + 名称 + 副标）；
- 一句话说明（章节/节数/离线状态）；
- 主 CTA（去闯关 / 开始阅读）；
- 分组导航（`nav-group-title` + 链接 + 序号）；
- 当前章节高亮（左侧色条 + 浅底）；
- 底部版本/日期/快捷键提示。

### 4.3 章首 / 小节

```html
<section class="sec" id="ch1">
  <div class="sec-head">
    <div class="sec-kicker">01 · MATH PRIMER</div>
    <h2>第一章 · 补课馆</h2>
    <p class="sec-desc">一句话说明这一章解决什么。</p>
  </div>
  <details class="sec-toc"><summary>本章目录 · 17 节</summary>…</details>
  <h3 class="sub-title">1. 函数：一台输入输出机器</h3>
  …
</section>
```

### 4.4 内容块

| 组件 | 要点 |
|---|---|
| 段落 | 每段 3–5 行；关键词加粗，不整段加粗 |
| 卡片 `.card` | 白底细边；标题在卡内用 h5/加粗 |
| 公式卡 | `FORMULA` 小标签 + TeX 居中 + 逐符号解释；可复制 |
| callout | 4 种语义：key（重点）/ tip（技巧）/ warn（警告）/ note（说明），颜色区分 |
| 表格 | 表头加深、行分隔、窄屏可横向滚动、宽表包 `.table-wrap` |
| 代码 | 等宽字体、浅底、语言标签、横向滚动 |
| 图 | 圆角、细边、图注 muted；宽度 100% |

### 4.5 阅读体验组件

- 顶部 3px 阅读进度条；
- 侧栏当前章节高亮；
- Ctrl/⌘+K 快速跳转（模糊搜索标题/正文前 120 字）；
- 深色模式（`[data-theme="dark"]` 覆盖 CSS 变量，不写两套样式）；
- 打印样式（隐藏侧栏/按钮/折叠摘要，展开所有折叠内容，黑白可读）；
- 手机：抽屉目录、单列、按钮 ≥44px、表格横向滚动；
- 论文/资料关：Q 节可折叠（默认展开 Q1）+ 展开/收起全部；
- 章末上一章/下一章；
- 小节标题锚点（悬停出现 `#`，点击复制/定位）。

## 5. 复用旧版设计：标准流程

用户说“旧版更好看”时，**不要重画**，按下面做：

1. **提取资产**：从旧 HTML 里取出 `<style>`（全部）、页面骨架（sidebar/toolbar/hero 的 HTML）、页面 JS（主题/搜索/进度/折叠）。
2. **落地为新文件**：`legacy.css` + `legacy_script.js` + `template.html`，先能原样跑起来。
3. **只替换内容区**：保留旧版类名（`.sec`、`.hero`、`.card`、`.callout`、`.formula-card`…），把新数据渲染成旧版期望的结构。
4. **补新功能**：在旧版样式上追加，不覆盖（新 CSS 放最后，类名前缀区分）。
5. **截图对照**：同尺寸截图旧版 vs 新版，逐项对比留白/字号/层级；不一致就问“旧版这里为什么好看”。
6. **回归审计**：旧版 JS 可能依赖旧 DOM（按旧 id/类补齐），跑渲染审计 + 交互冒烟。

常见坑：

- 旧版 CSS 只到“半高”，新内容类名（如 `.card-h`、`.term-line`）没样式 → 追加；
- 旧版 JS 依赖 `#nav-list`、`[data-jump]`、`#progress` → 骨架要补齐；
- 旧版是外链 MathJax → 换内联 SVG，避免断网翻车；
- 旧版内部锚点（`#primer` 等）在新结构里不存在 → 建锚点映射表统一重写。

## 6. 截图审查流程

每轮必看 4 张图：

1. 桌面首屏（1280×1000）：封面/hero 是否抓人、层级是否清楚；
2. 内容中段（滚动到某一章）：正文可读性、卡片/表格/公式是否协调；
3. 手机（375×812）：单列、按钮、横向滚动；
4. 深色模式 + 打印预览：对比度、隐藏元素、折叠展开。

审查顺序（每次只改 3 处）：

1. 第一眼是否“像正经作品”？（封面、字体、留白）
2. 第二眼是否“读得下去”？（行宽、行高、段距、对比）
3. 第三眼是否“完整”？（深色、打印、手机、搜索、进度）

## 7. 可访问性

- 正文对比度 ≥ 4.5:1；muted 文字用于非关键信息；
- 交互元素可键盘操作（Tab/Enter/Esc），焦点可见；
- 不依赖颜色单独传达信息（对错同时用图标/文字）；
- 尊重 `prefers-reduced-motion`，动画可关；
- 字体栈包含中文回退（PingFang/微软雅黑/思源）；
- 打印时隐藏交互，仅保留内容。

## 8. 设计验收清单

- [ ] 有封面：眉标 + 大标题 + 摘要 + 规格 chips + CTA
- [ ] 字体与版心统一；正文 65–75 字符宽、行高 ≥1.75
- [ ] 章首/小节/正文/辅助信息层级清晰
- [ ] 卡片、表格、公式、代码、callout 有一致样式
- [ ] 侧栏目录 + 当前章节高亮 + 阅读进度
- [ ] Ctrl+K 搜索可用；深色模式切换正常
- [ ] 打印预览：无侧栏/按钮，折叠内容展开，黑白可读
- [ ] 手机 375px：无横向滚动，按钮可点
- [ ] 与参考/旧版截图对比，无明显退步
- [ ] 公式离线渲染，无残留 `$`；图片不裂
