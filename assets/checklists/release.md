# 发布清单

## 交付物

- [ ] 最终单文件 HTML（命名清楚，带版本）
- [ ] README（怎么用 / 怎么改 / 内容边界）
- [ ] 审计记录（步数、0 问题、交互结果、离线结果）
- [ ] 可选：数据源、构建脚本、审计脚本、截图

## 体验

- [ ] 访客 3 分钟内能理解“这是什么、从哪开始”
- [ ] 首关到通关全流程无卡点
- [ ] 求助按钮存在（提示/剧透/自动演示）
- [ ] 题目解析说得清“为什么错”
- [ ] 手机可完成至少一关

## 质量

- [ ] 全量渲染 0 报错、0 空白
- [ ] 公式 0 未渲染、0 MathJax 错误
- [ ] 文本 0 瑕疵（冒号、重复标点、Markdown 残留、实体、丢字）
- [ ] 交互关全部可通关
- [ ] 断网可用
- [ ] 覆盖矩阵必须项 100%

## 边界

- [ ] 外部链接/工具版本标注“未核验”
- [ ] 引用材料标注来源，注意版权
- [ ] 不承诺“学会”，写清适用范围与前置要求
- [ ] 版本/日期记录在 README


## 双形态

- [ ] `game.html` + `study.html` 两件齐全，README 说明两者关系
- [ ] 学案可搜索、可打印；闯关可存档、可离线
- [ ] 两件互相链接正常
- [ ] 交叉一致性：术语、关键数字、章节命名一致
- [ ] 两套审计记录附在交付里
