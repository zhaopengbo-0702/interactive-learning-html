# 视觉设计检查清单（学案 / 文档形态）

## 第一眼（3 秒）

- [ ] 首屏有封面：眉标 + 大标题 + 摘要 + 规格信息 + 主 CTA
- [ ] 标题字体有性格（衬线/黑体一致），不是默认浏览器字体
- [ ] 主色 + 点缀色 ≤ 2 个，没有荧光色/渐变滥用
- [ ] 页面有明确留白，不贴边、不拥挤

## 阅读（30 秒）

- [ ] 正文宽度 65–75 字符；行高 ≥1.75
- [ ] 段落短（3–5 行），关键词少量加粗
- [ ] 章首 / 小节 / 正文 / 辅助信息层级一眼可辨
- [ ] 卡片、表格、公式卡、callout、代码块样式一致
- [ ] 表格窄屏可横向滚动；长公式可横向滚动
- [ ] 图片有圆角/边框/图注，不裂图

## 完整度

- [ ] 侧栏目录 + 当前章节高亮 + 顶部阅读进度
- [ ] Ctrl+K（或等价）搜索可跳转
- [ ] 深色模式可切换且对比度可读
- [ ] 打印预览：隐藏侧栏/按钮，折叠内容展开，黑白可读
- [ ] 手机 375px：单列、无横向滚动、按钮 ≥44px
- [ ] 论文/资料关：Q 节可折叠 + 展开/收起全部
- [ ] 章末上一章/下一章导航；小节标题锚点可复制

## 回归

- [ ] 旧版设计资产（CSS/骨架/JS）已复用，未因“重画”退步
- [ ] 与参考截图并排对比，无明显退步
- [ ] 公式离线渲染 0 残留；文本审计 0 瑕疵
- [ ] 设计源文件（css / template / js）已纳入仓库
